# 月球素材生成记录

工具：Codex 内置 ImageGen，`transparent_background: true`。非 API/CLI 调用。最终项目素材为 `public/assets/moon-source.png` 与 `public/assets/moon.webp`，WebP 经检查具有真实 alpha 通道。

提示词：

> Use case: stylized-concept. Asset type: transparent hero illustration for STMfan personal developer portfolio, inspired by the slogan To Decipher the Sublunary Sphere. Primary request: a single striking photorealistic sculptural moon sphere, detailed realistic lunar craters, pale silver-gray stone, a dark crescent shadow crossing lower right, raking studio light from upper left revealing tactile surface. Composition: the COMPLETE perfectly round moon centered with plenty of transparent margin, occupies 80 percent of a square frame, front view, no rings, no stars, no surrounding scene. Style: premium museum object photography meets astronomical realism, elegant, calm, cinematic, achromatic grayscale so it works across multiple webpage palettes. Constraints: actual transparent background with clean alpha edge, isolated moon only, no typography, no watermark, no branding, no extra objects, high detail.
