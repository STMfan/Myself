## 第二轮批注与实时调整

- 页头性别统一为 Male。联系胶囊增加「联系我 ↗ / Contact me ↗」，文字入口不随悬停上移；英文横屏为身份、设置与固定胶囊分别保留空间，竖屏使用两行页头。
- 移除首屏多余固定高度，将章节间距从桌面 132px / 手机 80px 收紧到 76px / 52px；技艺与联系段落独立收紧。首屏容器不再裁切月球，滚动视差可连续越过原边界。
- MaiBot 图标围绕中心顺时针旋转 35°，悬停只放大。
- 角色约每 2.8 秒上下交叉淡入淡出，图像不旋转；英文名按用户要求采用 Wriothesley、Varka、Von Lycann、Wang、Rashid。名称固定位置交叉淡入，字号上调。
- 选择胶囊在鼠标悬停、键盘聚焦或点击星球按钮时出现，具有对称的淡入淡出；放在卡片下沿外，避免遮挡名字。选择时自动暂停，提供手动暂停、方向键 / Home / End / Escape 操作；后台、视口外和减少动态效果时停止自动切换。
- 角色与唱片的桌面卡片显著降低高度。角色贴合底边裁切，头部、衣装可越过上方与侧边；唱片向右探出，中心封面占比增大。竖屏角色留在框内、唱片与文字并列，优先可读性及触控。
- 莱欧斯利使用内置 ImageGen 重新提取透明半身，按用户授权补全衣装轮廓；原图不修改。
- 页脚取消分割线，大字号 STMfan 与下方左对齐 slogan。删除静态配色页面、备用主题变量、配色偏好读取和对应入口，仅保留已选极地信号的亮暗模式。
- 后续截图发现月球跨入技术标签：滚动位移限制为 58px、整体旋转限制为 -10° 至 12°，离开首屏时渐隐；自动浮游与轨道动画保留。根容器仅裁切水平方向，不裁切首屏纵向边界。
- 耳机图标移至歌单说明旁，唱片前无图标叠放。「正在接取小型委托」定位 `#commissions`，直达付费委托卡片。
- 点选角色后移出鼠标会解除鼠标焦点、淡出胶囊并恢复自动播放；键盘焦点继续保留可操作的胶囊。所有角色名称后方使用统一的局部渐隐蒙版。
- QQ 使用用户指定的 Font Awesome SVG，原样保留文件内署名，通过 CSS 蒙版随亮暗主题显示；来源与 CC BY 4.0 声明纳入素材及发布声明。
