# 浏览器批注修订

延续用户确认的「极地信号」配色、中文暗色默认、MIT 原始源码协议。

| 批注 | 实现 |
| --- | --- |
| 1、7 | 将头像、姓名、性别和身份说明移入页头，移除首屏底部身份栏及字母标志 |
| 2、3 | 首屏按钮改为「我的作品」「联系我」，联系按钮使用电话图标并补上明确按钮外观 |
| 4 | 技术区换成四个独立展示场景：API 架构、服务器、全栈构建、移动屏幕；标签切换、磁性倾斜、信号路径、扫描与构建动画 |
| 5 | 付费委托与开源协作等宽并列，付费在前，描述各自边界 |
| 6 | 使用指定 MaiBot 图像，围绕图像中心轻微旋转，悬停保持位置稳定 |
| 8 | 邮件、GitHub、Bilibili 图标组成固定悬浮胶囊，始终可见 |
| 9 | 缩减首屏上方空白；「起点」导航回到完整页头 |
| 10 | 使用指定 Wikimedia 三角洲 Logo，浅色底保证黑色字标可辨 |
| 11、12、13 | 在对应游戏卡片添加 UID 279459622、UID 14846660、ID STM__fan，均可复制 |
| 14 | 删除独立 Minecraft 账号条 |
| 15 | 使用指定歌单封面，居中圆形裁切到唱片标签 |
| 16 | 取用用户本机五张素材，通过 Codex 内置 ImageGen 做透明半身抠图并转为 WebP |
| 追加动效要求 | 月球明显的自动浮游、旋转、缩放，叠加更大的滚动视差；轨道与引导线持续运动，页面边缘的进度线连接五个章节 |

技术展示是示意图，不声称为真实监控数据。所有自动动画响应减少动态效果；月球与技术场景的循环在离开视口时暂停。项目、文章占位与未来内容扩展方式保留。

具体素材来源、ImageGen 完整提示、文件校验值见 `ASSETS.md` 与 `public/assets/characters/sources.json`；验证范围见 `VALIDATION.md`。
